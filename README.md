# 減脂喵 / 減脂小工具

手機優先的靜態 PWA：今天練什麼、今天吃什麼、身體趨勢、部位圖、採買與規則。資料存在手機 `localStorage`，Garmin／InBody 快照在 `data.json`。目標是 12/31 前減脂 3–4 kg，體脂 15–16%，保肌。

線上版：https://smpss89119.github.io/fatmi-app/

## 本機開啟

```bash
python3 -m http.server 43123
```

瀏覽器開 `http://127.0.0.1:43123`。請用本機伺服器，不要直接雙擊 `index.html`。

## 更新 Garmin／InBody 資料

在有登入權杖的機器上執行：

```bash
/workspace/garmin-venv/bin/python /workspace/fatmi_export.py
```

會寫入 `/workspace/fatmi-deploy/data.json`（可用環境變數 `FATMI_EXPORT_PATH` 改路徑）。不會印出密碼或權杖。之後把 `data.json` 一併提交即可讓 App 讀到新數據。

## 首頁

由上往下：

1. **今天練**：週二課表 A、週五課表 B。前一晚睡眠滿 6 小時、靜止心率沒有比 7 日平均高 5 下，就練原課表；否則改家裡 25 分鐘快版，並附原因。休息日收成一行「休息日，走走路就好」。
2. **今天吃**：熱量環與蛋白環（140–160 g）。有 Garmin 時，熱量 = 昨天總消耗 − 450，最低 1800；沒資料時工作日 1900–2000、訓練日或步數多 2100–2200。四餐各一行，「照吃了」一鍵記錄。
3. **身體趨勢**：體重、體脂、骨骼肌。點進去看睡眠、靜止心率、運動心率。
4. **部位圖**：正面加背面，主要部位深色、輔助淺色；當週不到 6 組會標橘色。

底部分頁：今天、採買、規則。

## 訓練日節奏

16:00 先喝兩份樂維根蛋白粉（每份 40 g）：無糖芝麻／豆漿／杏仁各約 20 g 蛋白、約 170 kcal；極致植物優蛋白約 25 g 蛋白（熱量待確認）。選到一份極致，晚餐雞胸改 150 g；兩份都是 20 g，晚餐雞胸 200 g，或 21:00 再加蛋 2 顆並把雞胸改 150 g。大約 18:30–19:00 訓練，練完再吃晚餐。

標示「今天空腹練」，或按下開始訓練前早餐／午餐／練前餐都沒記錄，改做 25 分鐘快版，而且不追重量。

## 換一個

- 蛋白質可互換：雞胸 200g／150g、蝦仁 150g、吳郭魚排 1 片、雞蛋 3 顆或 2 顆
- 澱粉可互換：飯 150g、地瓜 150g、酸種麵包 2 片
- 也可改成樂維根無糖蛋白粉（scoop 數與每 scoop 估計值可改）

## 訓練模式

一次只顯示一個動作，左滑下一個。帶入上次重量／次數，大按鈕「完成」開始休息倒數；重量有變或次數不夠才需編輯（「少做了」）。結束時點下背 0–10 分，接著看今天練到的部位與本週組數。

連續兩次做滿且有餘力，下次提示加 1–2.5 kg。週五會幫不到 6 組的部位加一組補強。下背 3 分以上，下次深蹲改腿推。回台第一週重量抓上次七成，留 3 下。可一鍵改回原課表。Garmin 同一天的肌力紀錄會對上心率與時間。

## 自動更新

下拉重新整理會立刻重抓 `data.json`、版號與程式（`cache: no-store`），並讓 Service Worker `skipWaiting` 後整頁重載，本機訓練／飲食紀錄保留。App 回到前景或每約 10 分鐘也會檢查 `version.json`／`data.json`：新資料就地重畫；新程式版號會無縫重載，但訓練中或正在輸入時會延後，並跳出「已更新」。
