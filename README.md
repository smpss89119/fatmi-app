# 減脂喵 / 減脂小工具

手機優先的靜態小工具：訓練課表、訓練日／休息日菜單、採買清單、下背友善規則。無需登入。視覺與操作對齊「曼谷喵導遊」那類單欄、底部分頁、加到主畫面的迷你 App。

## 本機開啟

任選一種：

```bash
# Python
python3 -m http.server 43123

# Node
npx --yes serve -l 43123
```

瀏覽器開 `http://127.0.0.1:43123`。請用本機伺服器，不要直接雙擊 `index.html`（Service Worker 與離線快取需要 http）。

### 手機預覽

電腦與手機同一 Wi-Fi，把網址裡的 `127.0.0.1` 換成電腦區網 IP。iPhone 用 Safari 打開後：

1. 分享 → **加入主畫面**
2. 名稱維持「減脂喵」

Android Chrome：選單 → **加到主畫面**。

## 部署到 GitHub Pages

倉庫根目錄就是網站（`index.html`、`app.css`、`app.js`），和既有 github.io 小工具相同。

1. 把這個專案推進 GitHub
2. Settings → Pages → Build from **Deploy from a branch**
3. Branch 選 `main`、資料夾選 `/ (root)`
4. 網站會在 `https://<帳號>.github.io/<倉庫名>/`

若倉庫名不是根網域，相對路徑（`./`）已設好，子路徑也能用。`.nojekyll` 避免 GitHub 處理底線檔名。
